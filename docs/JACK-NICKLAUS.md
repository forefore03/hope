# 잭 니클라우스 골프클럽 코리아

확인일: 2026-11-11. 어반·링크스 각 1~9번은 사용자가 제공한 순서입니다.

원본 카카오 링크 18개를 해석하고 기존 플라밍고 32개 변환 좌표와 회귀 검증했습니다. 실제 그린 중앙·홀 대응의 현장 검증은 별도입니다.

공식 코스 안내: https://www.jacknicklausgolfclubkorea.com/course/tip

공식 표기는 White, yd. 미터는 1yd = 0.9144m로 환산 후 표시용 반올림했습니다. 실제 GPS 직선거리와 구분합니다.

원본 거리와 PAR는 각 홀 화면의 로딩 완료 및 홀 번호를 확인한 뒤 기록했습니다. 공식 거리표의 합계와 미터 환산 합계는 홀별 반올림 합계와 소폭 다를 수 있습니다.

독립 PROJ EPSG:5181 변환과 비교한 18개 좌표의 최대 차이는 1.56e-10도 미만입니다. 이는 좌표계 변환 검증이며 실제 그린 중앙의 현장 검증을 의미하지 않습니다.

앱의 전체 거리·진행바는 실제 티 시작 위치 기준을 유지하며, 공식 White 거리로 실측값을 덮어쓰지 않습니다.
