## 확인한 동작

1. 카카오맵에서 잭니클라우스GC코리아와 인천 연수구 아카데미로 209 주소를 확인했습니다.
2. 항공사진 30m 축척에서 하나의 그린 중앙에 표시된 9번 후보를 관찰했습니다.
3. 우클릭 메뉴의 `여기 주소 보기`를 선택했습니다. 처음에는 팝업이 클릭한 위치에 나타났습니다.
4. `지도공유 → URL 복사`로 실제 단축 링크를 얻었습니다.
5. 그 원본 링크를 다시 여니 분홍색 필지 경계와 주소 결과가 표시됐고, 파란 핀이 그린이 아닌 필지 서쪽으로 이동했습니다.
6. 주소 좌표를 골프장 대표 위치 참고값으로만 사용했으며, 그린 위경도는 모두 비워 뒀습니다.

## 판단

팝업이 클릭 위치에 뜬다는 사실과, 공유 링크가 그 위치를 보존한다는 사실은 다릅니다. 이번 UI 경로는 후자를 충족하지 못했습니다. 원본 URL 재현이 가능한 정확한 지점 공유 경로를 확보하기 전에는 A 방식의 9홀 성공을 주장할 수 없습니다.

좌표 변환·중복 검사·예외 목록·사용자 승인 후 승격 처리는 준비돼 있습니다. 카카오맵 UI에서 그린 지점 자체의 URL을 얻는 단계가 미해결입니다.
