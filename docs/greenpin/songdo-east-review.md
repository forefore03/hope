## 확인 범위와 예외

- 수집·변환 핀 확인 9개, 누락 0개. 사용자에게 홀별 클릭을 요청하지 않고 수집했습니다.
- 공식 전체 코스도의 EAST 라우팅과 카카오 지도 1~9번 상대 배치를 대조했습니다. WEST(지도 10~18번)는 이번 9홀 시험 범위에서 수집하지 않았습니다.
- 주로 50m 축척에서 번호와 단일 그린·핀 끝의 겹침을 확인했습니다. 1번 재수집 핀은 30m에서도 확인했습니다. 지도 표시와 현장 GPS 정확도는 별개입니다.
- 1번 첫 링크는 변환 핀이 그린 남쪽 약 43m 부근에 벗어나 채택하지 않았습니다. 원인은 확정하지 않았으며, 번호를 다시 지정해 한 번 재수집한 링크만 채택했습니다. 실패한 링크와 원본 XY는 관찰 파일의 예외 목록에 보존했습니다.
- 좌표가 표시된 핀과 주소 검색 결과 마커를 구분했습니다. 원본 URL의 주소 검색어를 바꾸거나 숫자 좌표를 주소 핀에 맞춰 보정하지 않았습니다.
- 숫자 좌표 변환 후 카카오 링크의 정수 반올림으로 XY가 1단위 달라질 수 있습니다. 원본 숫자는 보존하며, 실제 열린 핀을 기준으로 확인했습니다.
- 화이트티 거리는 공식 홈페이지의 표시 거리이며, 그린 좌표에서 계산한 티→그린 직선거리가 아닙니다.
- 기존 hope. 코스 데이터와 UI는 변경하지 않았습니다. 앱 등록은 검토 후 별도 진행합니다.
