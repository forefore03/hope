# hope.

## 거리만 알면 됐지.

공 옆에서 한 번 누르세요. 그린 중앙까지 남은 거리를 보여드립니다.

티샷은 얼마나 갔는지, 다음 샷은 얼마나 남았는지. 스코어와 클럽 선택은 늘 하던 대로.

**[hope. 열기 ↗](https://forefore03.github.io/hope/)**

현재 거리 측정은 **플라밍고CC · 링크스, 파크, 듄스**와 **잭 니클라우스 골프클럽 코리아 · 어반, 링크스**, **베르힐CC 영종 · 베르힐, 스카이, 오션, 레이크**에서 사용할 수 있습니다. 그린 좌표는 현장 검증 전이므로 캐디 안내와 함께 확인해주세요.

---

## 처음이라면, 이것만.

1. 골프장과 시작 코스·홀을 고릅니다.
2. **티박스에서, 샷을 하기 전에** **한 방 갑니다.**를 누릅니다.
3. 공 옆에 도착하면 **여기서 확인**을 누릅니다.

다음 홀에서는 화살표 **→**를 누르고, 새 티박스에서 다시 시작하세요.

## 집에서 미리보기

[미리보기 열기](https://forefore03.github.io/hope/?preview=1)에서 등록 골프장·코스·홀·사용 그린을 골라 조작을 확인할 수 있습니다. `여기서 확인`을 누르면 예시 거리가 바뀝니다. GPS와 사진·주차 정보를 사용하거나 실제 라운드를 변경하지 않습니다. `실제 앱으로 돌아가기`로 종료합니다.

## 라운드 전

### 차는 여기.

처음 열면 주차 화면이 나옵니다.

- **여기 주차했어 ↗**: 현재 주차 위치를 저장합니다. 위치 권한을 허용해주세요.
- **구역 사진 남기기**: 주차 구역이나 기둥 번호를 찍어둡니다. 지하주차장에서는 사진이 편합니다.
- **건너뛰고 시작**: 저장하지 않고 시작합니다.

위치와 사진은 둘 다 남겨도 됩니다. 저장한 주차 정보는 라운드가 끝난 뒤 **내 차 어디.**에서 확인합니다.

### 오늘은 된다.

**골프장 고르자** 또는 **현재 위치 확인**을 누르세요. 등록된 골프장 중 현재 위치에서 가까운 **3곳**이 나옵니다. 목록에서 골프장을 선택합니다.

지원 골프장을 선택했다면 **시작 코스**와 **시작 홀**을 확인하고 **가보자고**를 누릅니다. 링크스 출발이면 링크스, 듄스 출발이면 듄스. 실제 출발 코스로 고르세요.

주차 화면으로 돌아가려면 **주차 화면으로**를 누르세요. 사진과 선택 정보는 유지됩니다.

잘못 골랐다면 **골프장 선택 취소**로 다시 고를 수 있습니다. **그린 거리 측정 미지원**인 골프장은 아직 거리 측정이 되지 않습니다.

### 티샷 전에 한 컷.

**티샷 전에 한 컷 ↗**에서 사진을 찍거나 고를 수 있습니다. 시작 과정에서 사진 화면이 나오더라도 사진 없이 계속할 수 있습니다.

사진을 선택하면 문구가 들어간 카드가 만들어집니다.

| 하고 싶은 일 | 누를 곳 |
| --- | --- |
| 문구 바꾸기 | **다른 문구 ↻** |
| 동반자에게 보내기 | **카드 공유 ↗** |
| 카드 파일로 저장하기 | **카드 저장 ↓** |
| 라운드 계속하기 | **좋아, 계속하자 →** |

공유 기능이 지원되지 않는 브라우저에서는 카드를 저장한 뒤 사진 앱이나 메신저에서 보내세요.

## 티박스에서

### 한 방 갑니다.

**티박스로 이동하셨어요?** 화면에서는 실제 샷을 할 자리로 이동한 뒤 **한 방 갑니다.**를 누르세요.

이때 현재 위치가 그 홀의 시작점이 됩니다. **전체 거리**는 시작점에서 선택한 그린 중앙까지의 직선거리로 정해집니다. 골프장 거리표와 다를 수 있습니다.

두 그린이 있는 홀에서는 **사용 그린**을 확인하세요. 거리 화면에서도 바꿀 수 있습니다.

| 코스 · 홀 | 선택 표시 |
| --- | --- |
| 링크스 4번 | Green A / Green B — 좌우 구분 미확정 |
| 듄스 3번 · 8번 | 좌그린 / 우그린 |

어느 그린을 사용하는지는 캐디에게 확인하세요. 앱이 당일 사용 그린을 자동으로 알아내지는 않습니다.

## 공 옆에서

### 큰 숫자 하나면 됩니다.

공 옆에 도착하면 **여기서 확인**을 누르세요. **가장 큰 숫자**가 현재 위치에서 선택한 **그린 중앙까지 남은 거리**입니다. 거리 단위는 미터입니다.

| 화면에 보이는 것 | 의미 |
| --- | --- |
| 가장 큰 숫자 | 마지막으로 측정한 위치 → 그린 중앙 |
| 첫 확인 때 아래에 나오는 숫자 | 티 시작점 → 현재 위치의 직선거리. 티샷 거리 참고값 |
| 전체 거리 | 티박스에서 시작할 때 정한 전체 직선거리 |
| 배경의 초록 영역 | 전체 거리 대비 그린에 가까워진 정도 |

숫자와 배경은 **확인할 때 갱신**됩니다. 걸어가는 동안 자동으로 계속 움직이지 않습니다. 배경은 공의 이동 경로나 휘어진 홀의 길이를 나타내지 않습니다.

티샷 거리 참고값은 **그 홀에서 처음 확인할 때만** 나타납니다. 두 번째 확인부터는 사라지고 남은 거리에 집중합니다. 샷을 했는지 자동으로 판단하는 방식은 아닙니다.

### 버튼 대신, 화면을 톡.

거리 숫자가 있는 영역에서도 조작할 수 있습니다.

- **한 번 톡**: 현재 위치에서 거리 확인.
- **빠르게 두 번 톡**: 다음 홀 이동 확인창 열기.

확실하게 누르고 싶다면 아래의 **여기서 확인**과 **→** 버튼을 사용하세요. 다음 홀은 확인창에서 **이동**을 눌러야 바뀝니다.

### “나는 얼마나 남았어?”

동반자의 공 옆으로 가서 **여기서 확인**을 누르면 됩니다. 남은 거리는 방금 측정한 위치 기준으로 바뀌고, 내 티 시작점은 그대로 유지됩니다.

아래 티샷 거리 숫자가 아직 보이는 첫 확인이라면, 그 숫자도 동반자의 공 위치를 기준으로 계산됩니다. 내 티샷 거리를 보고 싶다면 내 공 옆에서 먼저 확인하세요.

## 다음 홀로

**→ → 이동**을 누르고 다음 티박스로 갑니다. 새 티박스에서 **한 방 갑니다.**를 누르면 그 홀의 측정이 시작됩니다.

9번 홀을 마치면 이동 확인창에서 **다음 코스**를 고릅니다. 자동으로 선택된 코스가 실제 후반 코스와 맞는지 확인하세요.

앱을 잠시 닫았다가 이어 쓰면 이전 측정값이 나올 수 있습니다. 공 옆에서 **여기서 확인**을 눌러 새 위치로 갱신하세요.

## 라운드가 끝나면

### 오늘도 살아서.

18홀 진행을 마치거나 **오늘은 여기까지 → 마치기**를 누르면 마무리 화면이 나옵니다.

- **오늘의 카드 공유 ↗**: 사진이 있다면 카드를 저장하거나 공유합니다.
- **사진 남길래?**: 사진이 없다면 마지막으로 한 장 남깁니다.
- **내 차 어디.**: 주차 사진과 위치를 확인합니다. 저장한 위치는 카카오맵으로 열 수 있습니다.
- **그냥 갈게.**: 앱에 남은 사진·주차 정보·라운드 상태를 비웁니다.

**카드를 챙기고, 차를 찾은 다음에 ‘그냥 갈게.’를 누르세요.** 이미 외부에 공유하거나 저장한 카드까지 지워지지는 않습니다.

차를 찾은 뒤 **차 찾았어 · 주차 정보 비우기**를 누르면 주차 정보만 먼저 지울 수도 있습니다.

## 알아두면 편합니다

### 거리가 바로 나오지 않아요.

야외에서 위치 권한을 허용한 뒤 다시 눌러주세요. 위치 확인이 늦거나 오차가 크면 측정을 완료하지 못할 수 있습니다.

실패했을 때 남아 있는 숫자는 **이전 측정값**일 수 있습니다. 숫자와 함께 표시되는 측정 상태를 확인하세요.

### 집에서 미리 켜봤어요.

첫 화면과 사진 카드는 사용할 수 있습니다. 다만 선택한 홀에서 **5km 이상** 떨어져 있으면 실제 홀 거리 측정을 시작할 수 없습니다.

### 골프장 거리표와 달라요.

hope.는 **실제 시작 위치와 현재 위치에서 그린 중앙까지의 직선거리**를 계산합니다. 굽은 홀을 따라 잰 거리, 앞핀·뒷핀 거리, 고저차 보정 거리와는 다릅니다. GPS 오차와 등록 좌표의 오차도 영향을 줍니다.

### 사진과 위치가 계속 남나요?

자체 서버에는 사진·주차 위치·개인 측정값을 업로드하지 않습니다. 라운드를 이어 쓰기 위한 자료는 사용한 브라우저에 임시로 남습니다.

- **그냥 갈게.**를 누르면 개인 자료를 지웁니다.
- **새로운 하루 시작 ↗**을 누르면 이전 당일 자료를 초기화합니다.
- 탭을 닫기만 하면 즉시 삭제되지는 않습니다. 라운드 복원은 12시간, 당일 사진·주차 상태는 24시간 유효하며, 기간이 지난 자료는 다음 실행 때 정리합니다.

영구 보관하려는 카드는 종료 전에 직접 저장하거나 공유해주세요.

## 구성

- `dist/`: 그대로 배포하는 정적 웹앱. 별도의 설치·빌드·API 키·서버 DB가 필요하지 않습니다.
- `dist/data/flamingo.json`: 플라밍고CC 링크스·파크·듄스 각 9홀, 그린 30개 및 참고 티 위치 2개. 원본 링크와 검증 상태를 포함합니다.
- `dist/data/jack-nicklaus-korea.json`: 잭 니클라우스 어반·링크스 18홀 그린 좌표와 공식 White 티 거리(yd 및 m 환산).
- `dist/data/verthill-yeongjong.json`: 베르힐CC 영종 4코스 36홀, 그린 69개와 공식 화이트티 거리(m). 사진에서 추출한 좌표로, 사용자 검토 후 사용을 승인했으며 현장 실측 전입니다.
- [잭 니클라우스 공식 거리 확인표](docs/JACK-NICKLAUS.md): 2026-11-11 확인. GPS 실측과 구분합니다.
- `tests/`: 거리 계산·코스 데이터·라운드 흐름 테스트.
- `.github/workflows/pages.yml`: 테스트 후 `dist`를 GitHub Pages에 배포합니다.
- `COURSE-DATA.md`, `DUNES.md`: 좌표 출처와 검증 제한.

## GitHub Pages

1. `main` 브랜치에 이 폴더의 내용을 업로드합니다.
2. 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정합니다.
3. Actions에서 Deploy hope.를 실행합니다. 이후 main에 변경을 올리면 자동으로 테스트·배포합니다.

앱은 상대경로를 사용하므로 `/hope/` 같은 프로젝트 경로에서도 사용할 수 있습니다. GPS와 사진 공유는 HTTPS 환경 및 기기 권한이 필요합니다.

## 개발 확인

Node.js 22 이상에서:

```sh
node --test tests/*.test.mjs
```

로컬 미리보기:

```sh
python3 -m http.server 8000 --directory dist
```

실제 휴대전화 GPS 검증은 HTTPS 배포 주소에서 진행합니다.

골프장 좌표는 소스에 보관합니다. 좌표 출처 확인과 현장 정확도 검증은 구분하며, 홀 번호·그린 중앙·좌우 구분의 현장 검증은 완료되지 않았습니다.

폰트 라이선스는 `dist/*LICENSE.txt`에 보존되어 있습니다.
